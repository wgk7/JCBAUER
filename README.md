# 🏗️ JC BAUER — Sistema Integrado de Gestão de Compras, Almoxarifado & Obras

Sistema completo de ERP e Inteligência Operacional para Construtora e Incorporadora **JC BAUER**, conectando em tempo real a Diretoria, Compradores, Engenheiros de Canteiro e Almoxarifado.

---

## 🚀 Principais Módulos do Sistema

1. **Painel de Operações de Compras:**
   - Gestão de Requisições de Obra (RMs) com prioridade (Baixa, Média, Alta, Urgente).
   - Matriz de Cotações com fornecedores, condições de pagamento e prazos de entrega.
   - Emissão de Ordens de Compra (OCs) com cálculo automático de Saving.

2. **💰 BI Financeiro & Desempenho de Obras (Dedicado):**
   - Gráfico diário interativo de volume de compras vs. saving gerado.
   - Indicadores por canteiro: Orçamento aprovado, demandado, contratado, saldo disponível e custo médio por m².
   - Funil e pipeline financeiro de requisições de ponta a ponta.
   - Cronograma de fluxo de caixa e projeção de desembolso por faixas de vencimento (7d, 15d, 30d, 60d, 90d+).
   - Análise de economia por famílias de insumos e Top 5 vitórias de negociação.

3. **Arquitetura Integrada de Canteiro (Engenheiro & Almoxarife):**
   - **Central de Inspeção & Recebimento Físico:** Conferência cega com NF-e, lote, fotos de avaria e aceite de qualidade.
   - **Controle de Estoque & Ponto de Reposição:** Alertas automáticos de estoque mínimo para evitar paralisações no canteiro.
   - **Rastreabilidade de Aplicação:** Vínculo de insumos entregues com etapas da obra (Fundação, Estrutura, Alvenaria, Acabamento).

4. **Gestão de Obras & Empreendimentos:**
   - Acompanhamento simultâneo de empreendimentos (Horizon Tower, Atrium Bauer, SulPark Logístico).

---

## 🛠️ Tecnologias Utilizadas

- **Frontend & Fullstack:** Next.js 14+ (App Router), React 18, TypeScript
- **Estilização:** Tailwind CSS, Lucide React (Ícones)
- **Banco de Dados & ORM:** Prisma ORM
- **Exportação & BI:** Utilitários para relatórios executivos em PDF/XLS e gráficos interativos

## 📦 Como Executar o Projeto Localmente

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/SEU_USUARIO/jc-bauer.git
   cd jc-bauer
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. **Acesse no navegador:**
   [http://localhost:3000](http://localhost:3000)
